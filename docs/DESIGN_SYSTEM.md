# Navigation

Transparent over Hero.

Blur after scrolling.

Sticky.

Minimal.

Mobile menu should cover the screen.

# Hero

Hero should occupy almost the full viewport.

One strong headline.

One supporting paragraph.

One primary CTA.

Large visual.

Avoid multiple CTAs.
