# PROMPT_GUIDE.md

Prompt Rules

Always modify one feature only.

Never redesign unrelated components.

Respect AGENTS.md.

Respect DESIGN_SYSTEM.md.

Respect VISION.md.

Respect ROADMAP.md.

Prefer editing existing components.

Avoid creating duplicate components.

Explain only when necessary.

Keep outputs concise.

Focus on implementation.
